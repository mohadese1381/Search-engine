# Search Engine

A simple text-search engine implemented in **C#/.NET Core**, built as a self-study project to explore fundamental information-retrieval concepts.

## Features
- Reads and processes multiple text files  
- Builds a **custom inverted index** for fast lookup  
- Supports case-insensitive word search  
- Console-based user interface  

## Core Techniques
- Inverted index construction  
- Tokenization & basic text normalization  
- Efficient file I/O operations  
- Dictionary- and list-based search structures  

## How to Run
1. Clone the repository  
2. Add `.txt` files to the `SampleTexts` folder  
3. Run:

```bash
dotnet run
````

## Project Goal

Practice IR fundamentals (indexing + search) and gain hands-on experience implementing a lightweight search engine using C#.
